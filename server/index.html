伺服器指令手冊

2017 MacBook Pro · Ubuntu Server 24.04 LTS

SSH 登入

在新 Mac 的終端機執行。登入後，後面各節的指令都在 Ubuntu 伺服器上執行。

只在這個瀏覽器儲存連線資料。

連線到 Ubuntu

ssh USERNAME@SERVER_IP

螢幕與鍵盤亮度

用數值直接調整亮度。這台 Mac 的螢幕範圍是 0–90，鍵盤背光範圍是 0–255。螢幕建議從 45 開始，0 可能讓畫面全黑。

螢幕亮度約 50%

echo 45 | sudo tee /sys/class/backlight/acpi_video0/brightness

鍵盤背光約 50%

echo 128 | sudo tee /sys/class/leds/spi::kbd_backlight/brightness

關閉鍵盤背光

echo 0 | sudo tee /sys/class/leds/spi::kbd_backlight/brightness

讀取目前的亮度

cat /sys/class/backlight/acpi_video0/actual_brightness
cat /sys/class/leds/spi::kbd_backlight/brightness

Wi-Fi 與 IP

Wi-Fi 介面是 wlp2s0。路由器可能重新分配 IP，登入位置有變時可從伺服器本機查詢。

查看 Wi-Fi IP 和預設路由

ip -br -4 addr show dev wlp2s0
ip -4 route show default

查看 Wi-Fi 連線狀態

networkctl status wlp2s0 --no-pager

Touch Bar 排查

如果按鍵有亮、亮度卻沒變，先檢查亮度服務與最近的紀錄。

查看亮度服務

systemctl status macbook-touchbar-brightness.service --no-pager
journalctl -b -u macbook-touchbar-brightness.service -n 20 --no-pager

重新啟動亮度服務

sudo systemctl restart macbook-touchbar-brightness.service

確認 T1 iBridge 是否啟動

lsusb -d 05ac:8600

系統狀態與維護

查看開機時間、記憶體和磁碟

uptime -p
free -h
df -h /

重開機會中斷目前的 SSH 連線。伺服器開機後，再執行 SSH 登入指令。

重開伺服器

sudo reboot
